# X3 Timer

X3 Timer is a dual-mode timer utility for the RayNeo X3 Pro AR glasses, built as a small, glanceable heads-up display rather than a full-screen app: the core widget occupies under a fifth of the screen, with everything else transparent, so it floats in peripheral vision without blocking the wearer's view. It offers a Pomodoro focus mode that auto-minimizes to a small corner chip during uninterrupted work and expands again the moment you interact, plus a synthwave-styled Athletic mode covering HIIT/Tabata, EMOM, and AMRAP interval training with color-coded status pulses at the screen edge. Pomodoro sessions bind directly to tasks from a local list and log completions automatically, with a persisted day-streak and a seven-day sparkline shown on the idle screen. A short countdown-confirm gesture guards against accidentally switching modes mid-session.

## Controls

- Tap to start or pause
- Double-tap to reset the current program
- Swipe left or right on the right temple pad to switch between Pomodoro, HIIT, EMOM, and AMRAP
- Swipe up to extend a Pomodoro focus block, skip an interval, or add an AMRAP lap
- Swipe down to cycle the bound task (Pomodoro) or mute (Athletic modes)
- Tap the left temple pad to toggle mute
